# 🍎 Apple macOS Inspired Portfolio

A modern, interactive web experience inspired by Apple's MacOS. This project created as my personal portfolio to showcase my works.
Built with React, Tailwind CSS, GSAP and Zustand to explore immersive animations and smooth scrolling interactions.

## ✨ Features

-Apple MacOS inspired user interface with apple liquid glass effect.
-Interactive application windows
-Clean and modern design.
-Smooth scroll triggered animations.
-Smooth transition animations.
-Resusable react component.
-Dock-inspired navigation

## 🛠️ Tech Stack

React - Build UI components
Tailwind CSS - Modern styles
GSAP - Advanced animations
Vite - Development server and build tooling

## 🎯 Project Goals

-Showcase my personal details, education, projects and skills.
-Better understand about the React reusable components and tailwind css support.
-Learn web animation with GSAP animation library.
-Study about the state management with Zustand and immer library.
